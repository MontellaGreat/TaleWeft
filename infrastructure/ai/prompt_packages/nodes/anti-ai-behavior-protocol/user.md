━━━ 核心协议（P1-P5 · 不可违反）━━━

P1. 信息密度法则（写章硬指标）
  每个段落必须推进以下至少一项：剧情事实、角色关系、悬念线索、信息差变化。
  以换段为准：每段至少落地一类可复述事件——具体动作带后果、有信息对白、发现/决定、或可见位移；禁止连续两段纯写景无人物动作与取舍。
  写完一段后自查：这段删掉会影响读者理解吗？不会就删掉。

P2. 感官优先法则
  当你需要表达情绪或氛围时，执行顺序：
  感官细节（温度/光线/声音/触感/气味）→ 动作变化 → 对话内容
  禁止跳过前两步直接写情绪标签。

P3. 角色差异化法则
  不同角色面对同一事件的反应方式必须不同。
  反应方式 = 角色背景 × 当前身体状态 × 与事件的利益关系。
  每个角色有专属紧张习惯：{nervous_habits}

P4. 节奏与段落法则
  每个自然段最多使用一个中文句号；陈述段落在段末收束，段内逻辑分句按语义用逗号、分号或连词衔接。
  问句、感叹句按语气使用问号、叹号，标题及无须句号的条目不硬补句号；不得机械替换标点、遗漏事实或生硬换段凑数。
  节奏快 → 逻辑分句短促，动词前移，主语可省；同一动作链的分句有机聚合，不得每个分句独占一行。
  节奏慢 → 逻辑分句长短交替，感官细节穿插，铺陈段落可由2-5个逻辑分句有机聚合，在段末统一收束。
  禁止连续3个以上长度相近的逻辑分句。
  全章极短段比例不得超过15%，仅限冲突引爆、重大揭露或情绪暴击的瞬间使用；单个句号收束不等于必须写成极短段。

P5. 衔接法则
  节拍间无断点。情绪有惯性。
  上一段在愤怒，这一段不能突然平静。
  禁止用时间词（后来/之后/转眼间）开头省略过渡。

━━━ 替换策略（检测到B类模式时执行）━━━

R1. 情绪 → 找到角色此刻最可能做的小动作（手停住/话顿了一下/杯子端到嘴边又放下）
R2. 微表情 → 写完整姿态变化，或不写，让对白本身传递
R3. 比喻 → 写此刻的体温、光线角度、衣料触感
R4. 声线 → 用对白的标点和断句表现语气
R5. 纠正式对照 → 改成平叙逻辑分句，或直接写动作与结果
R6. 破折号 → 按语义用逗号、分号或连词衔接，在段末统一收束，不向同一自然段追加句号
R7. 动物比喻 → 删掉，用人的动作描写
R8. 生理性 → 直接写生理反应（眼睛酸了/鼻子红了/声音发闷）
