# 公开示例书《雾港来信·功能测试》

这是为叙织自编的悬疑短篇测试素材，不包含用户作品、运行时数据库、模型档案或 API Key。共 6 章：前 2 章有短篇样稿，后 4 章为空稿，供续写与功能测试使用。

## 桌面用户：直接导入稿件 JSON

下载 [fog-harbor.taleweft.json](fog-harbor.taleweft.json)，在软件的“稿件 JSON 导入”入口选择此文件，先检查预览再确认。不需要安装 Python，也不需要 API Key。

此 JSON 使用现有带 SHA-256 校验的稿件交换格式，**仅包含作品元数据、章节名、正文和空大纲**。它不包含人物、地点、世界规则、知识、道具、伏笔、结构或快照，也不含模型配置。安装包不会预置开发机样书库；需要完整功能测试资料的源码用户可使用下面的辅助脚本。

如果要在桌面版里体验包含设定、人物、地点、道具、伏笔和结构的完整测试书库，请从 GitHub Release 下载 `TaleWeft-0.1.0-preview.1-full-sample-data.zip` 和 `TaleWeft-0.1.0-preview.1-sample-launcher.zip`，解压启动器并运行 `launch_full_sample.cmd`。在两个文件选择窗口中选已安装的 `TaleWeft.exe` 和完整测试书库压缩包。工具会在 `%LOCALAPPDATA%` 创建唯一的隔离数据目录，再用它启动应用，不改动默认作品库；测试库内有 2 章样稿、4 章空稿和完整的资料面板数据，不包含模型档案或凭据。首次生成正文等模型功能仍需要配置自己的服务。

## 源码用户：导入完整测试资料

在项目根目录、已安装项目 Python 依赖的环境中执行：

```powershell
python scripts/install_sample_book.py --data-dir .\examples\sample-data
```

`--data-dir` 必须明确指定。导入已使用的数据目录前，请先关闭使用该目录的叙织实例。工具获取同一数据目录的独占锁；软件运行中会拒绝导入。使用另一个空目录可单独体验样书，不影响自己的书库。

完整导入通过现有公开 HTTP 路由在本地进程中执行，不启动网络服务器，不调用 AI，不需要 API Key。它会建立作品、章节、人物、地点、世界规则、时间线、文风约定、知识事实、道具、伏笔、三幕结构、人工审阅记录、实体提及和初始快照。导入不会复制或修改模型档案和凭据。

导入成功后，使用相同数据目录启动应用，书架会显示《雾港来信·功能测试》。例如在源码环境的 PowerShell 中：

```powershell
$env:TALEWEFT_PROD_DATA_DIR = (Resolve-Path .\examples\sample-data).Path
python scripts/run_local_secure.py
```

也可以将 `--data-dir` 指向桌面版实际使用的数据目录；请通过软件的数据目录入口确认位置，先关闭应用再执行脚本。

重复执行会提示 `existing edits preserved`，保留已修改的章节名、正文和其他资料，不重复建书。同名但不同 ID 的作品会阻止导入；同 ID 却缺少完整导入回执也会阻止，保留已有资料供人工检查。首次导入中断后不会自动删除或重建部分资料。

## 建议体验

1. 在作者书桌阅读前两章，修改第一章标题或正文，保存并查看历史。
2. 完整资料安装后，查看世界观中的林澄、周渡、雾港和九十二号仓库；打开知识、道具、伏笔与结构树。仅导入稿件 JSON 时，需要自行创建这些设定。
3. 配置自己的模型后再测试第三章续写、去 AI 味、审阅和关联重算；这些 AI 操作可能产生供应商费用。
4. 重跑导入命令，确认第一章修改仍然保留。

`sample-data/` 是本机生成的数据目录，应保持在 Git 忽略规则内，不作为公开发行附件上传。
