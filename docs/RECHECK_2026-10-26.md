# 叙织历史问题复查与修复

版本：0.1.0-preview.12。日期：2026-10-26。

本轮以当前 TaleWeft 开源源码、现有提示词及 DAG/调用持久化实现为基础，分三组交叉复查。用户数据库只读取证；真实模型验证在项目 out 目录中的私有数据库副本执行。没有用自动通过、跳过审稿、填占位内容的办法解除保存错误。

## geography 报错的实际原因

只读检查桌面版最近三次失败检查点，均停在 geography 的结构校验，候选只包含 terrain。对应原始模型回答实际上包含 terrain、climate、resources、ecology 四项；每项末尾多出的闭合括号使字段错位，原始 JSON 无法解析。既有 json_repair 修复成可解析对象时，仅保留了 geography 中的 terrain。

原校验阻止残缺资料写入是正确行为，但“继续生成”仅从 validate 重复检查同一份残缺候选，没有重新补齐它；因此连续点击继续仍失败。没有将 climate 等字段随意猜测搬到 geography。

本轮修复：

- 结构失败明确列出缺失、过短或过长的字段及中文含义。
- 在失败节点保留当前候选和同一调用会话的原始回答，交给真实模型按完整字段契约修复；同样适用于五个维度。
- 每轮最多两次结构修复，网络故障保留进度，用户继续时获得新的有界修复机会。
- 成功修复生成新的候选与调用来源，清除旧审计，再做真实偏离检测和语义 Anti-AI 审稿。
- 在偏离/Anti-AI 改写后产生结构缺失的情况，也能从该审核节点继续修复。
- 完整世界观复审统一五维字段的持久化表示；恢复旧结构候选时核对调用来源，再清除旧审计。实际保存结果必须与已审核候选一致。
- 最后一轮对抗发现旧版完整世界观已提交、但格式转换使回读失败的任务仍会卡住。补齐严格迁移：从原始采纳及成功提交重算规范化结果，重新双审稿；重审要求修改时创建新的采纳和提交。其他作者编辑仍受保护，精确回读后才将调用状态设为完成。

## 验证与限制

真实模型专项已经完成结构修复、偏离审稿和 Anti-AI 语义审稿：同一份桌面失败记录在隔离副本恢复出四个字段，长度分别为 125、121、119、125 字。后一次完整保留证据的三次调用用时 31.38 秒；恢复持久化检查点后，在取得独占租约、启用正式单 writer 队列的条件下成功提交，再连续两次回读，均与已审核候选一致，writer 失败数为 0。原始作者书库未被改写。

真实测试脚手架曾因没有取得执行租约、从标准输入启动 Windows 多进程而失败；之后改为真实脚本启动并按正式流程取得租约，保存与回读验证才通过。没有为测试放宽应用的租约、审稿或保存校验。该验证证明 geography 的这次真实恢复链路，没有宣称本轮已用真实模型重新生成整本小说。

最终合并回归实际执行 2000 项，结果为 **1995 passed、5 skipped、0 failures、0 errors**，耗时 507.07 秒。包含新增的 8 项旧成功提交恢复回归，以及分类、画像提示词和 1 万字边界的 76 项历史专用回归；各专项数量与这次统一运行重叠，不另行相加。XML 为 out/recheck-20261026/backend-release-final.xml。

5 项跳过是需要独立配置的 Anthropic 摘要与 OpenAI 嵌入真实 API 集成用例。它们没有使用桌面档案的密钥自动替代专用配置；上面 geography 的真实模型验证是另行明确执行的隔离专项。

前端完整单元回归 **266 项 / 29 文件通过**；浏览器回归 **15 项通过**，覆盖模型控制台、向导恢复、窄屏按钮和审核报告查看。浏览器测试使用固定接口夹具，不代表真实远程模型创作验收。生产前端构建与 vue-tsc 通过。

补跑历史画像提示词用例时，3 个旧 Provider 替身只提供 generate，缺少现行流式接口。测试替身补齐等价 stream_generate；快照隔离用例显式模拟不可重试错误，保留原市场画像、元数据、提示词和修复顺序断言。单文件 21 项先通过，随后随最终 2000 项合并执行通过；正式审稿仍使用流式调用。

构建状态和安装包校验见本轮发布说明。

离线故障注入验证了拒绝伪造证据、取消、恢复、并发写入和参数处理；它不能证明所有供应商始终在线，或 AI 审稿具有确定性。524 是上游网关超时，应用侧修复恢复/停止/状态链路，不能消除上游超时本身。

本轮没有重新逐一联网检索小说网站分类，也没有重新执行完整安装/升级/卸载全矩阵或本地嵌入权重的完整下载与离线语义推理。国内源及镜像回退、文件完整性门禁有自动化回归，不能据此保证任意网络现在都可下载。分类后端历史专用用例已补跑，但本轮未逐条重审所有主题画像的文字质量，部分平台映射和画像仍须作者核对。
