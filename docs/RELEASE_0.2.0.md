# 叙织 · TaleWeft 0.2.0

整理日期：2026-10-28。0.2.0 汇总首次 GitHub 版 `0.1.0-preview.1` 之后、preview.2 至 preview.16 已实现的更新，并统一当前版本号。历史版本说明、原始审核证据和既有校验记录继续保留；本次版本号调整不会把旧记录改记为 0.2.0 验证。

发行页：[v0.2.0](https://github.com/MontellaGreat/TaleWeft/releases/tag/v0.2.0)。本版已完成下述构建和验证；源码以 `v0.2.0` 标签为准，安装器及其余附件在发行页提供，下载后按 `SHA256SUMS.txt` 校验。公开构建记录将安装器 SHA-256 绑定到该标签对应的完整源码提交。

## 主要更新

### 模型自动协议与思考参数

- OpenAI C / R 合并为 **OpenAI 自动**，优先 Responses，仅在明确不支持端点、且尚未输出正文时尝试 Chat Completions。鉴权、限流、502、超时或模型参数错误保留真实原因，避免误切协议和重复生成。
- 保留 Anthropic Messages、Gemini generateContent 及主力、经济、知识图谱角色配置；思考程度或预算置于模型名下方，参数保存、就绪检查、连接测试与请求构造共用能力限制。
- 移除厂商预设导入与档案预设选择，拉取模型后直接显示可搜索列表，失败或空列表时仍可手填；异步刷新不覆盖新草稿。
- 修复 Responses 扩展参数传递、SDK 与地址兼容，以及托管启动命令消费、执行器存活检查和租约续期。真实并发冲突继续受保护。

### 本地嵌入与开书检查

新书入口和最终建档前检查语言模型及嵌入模型，缺项时保留表单并打开对应设置。只读就绪检查不会请求付费模型，也不代表远端已连通。

新配置默认采用本地 `BAAI/bge-small-zh-v1.5`，已保存的云端配置继续保留。“下载并准备本地模型”覆盖依赖安装、来源探测、权重下载、完整性校验与完整模型发布，优先魔搭国内源，再回退 HF 镜像和官方源。补齐下载心跳、终止事件、取消、临时文件与锁处理，修复冻结程序 Python、DLL 和向量索引兼容。历史实测已在对应环境离线加载默认 BGE 并生成 512 维向量，不能推及全部自备模型或任意网络。

### 新书 DAG：真实偏离审阅、Anti-AI 与断点继续

文风公约、五维世界观逐单元生成，之后进入人物、地图和剧情总纲。世界观阶段 48 个节点，其他三阶段各 7 个节点；进度按已完成节点计算，提供当前动作、实际等待时间、接收字符数、节点详情和错误。

每个单元依次完成生成、结构校验、偏离检测与修复、Anti-AI、保存及回读。偏离检测核对基础设定和前置资料的真实模型审阅证据；Anti-AI 将本地规则扫描与模型五维语义审稿分别记录，语义审稿检查空泛抒情、解释腔、机械结构、情绪标签与模板收尾。本地零命中不能跳过语义审稿；报告须覆盖有效文本，问题须附逐字原文、原因和修改建议。修复后重新审阅，不以哈希或一个通过标志代替模型回执。

失败、取消或重启后可继续当前检查点，保留候选及成功步骤。复用须匹配会话、实际提示词、候选修订、前置上下文与真实成功调用，使用前仍校验报告；输入实际变化时重新执行受影响阶段。修复结构化文风误判、市场快照错配、世界观 JSON 错位、人物声线丢失和保存回读差异，已提交旧任务按原证据恢复，避免覆盖作者新修改。

审核和修复改用流式聚合，短编号覆盖回执减少模型复写长哈希错误，多请求审核按单次请求独立计时，并保留有限总预算。超时、无效 JSON、部分输出和无改动修复仍会失败，不自动当作审核通过。DAG 展示精简重复报告，完整原文与证据继续保留；旧执行图缺失的新审核不会补造。

### 叙事结构 502 后的状态与恢复

修复网关 502 后失败回执未持久保存、遗留待处理请求反复等待，以及侧栏把等待审阅误显示为持续生成的状态链。新失败与取消保存真实 attempt、会话和错误，界面按持久请求显示生成、待处理、失败、停止或中断。收到的结构预览会保留，正式结构成功读回前不显示已完成；观察流断开后继续查询状态。

侧栏“打开运行中心处理”可进入“检查并恢复 AI 请求”。打开入口只查询，重新请求、继续、采纳与确认写入分别由作者操作。停止期间确认的恢复结果持久保存，下次明确启动托管时复用并写入结构树，写入失败保留结果，不因此再次请求模型。已有旧卷结构也先处理恢复结果；目标章节数变化、并发批准或执行租约冲突会阻止过期提交。旧版缺少调用回执时仍需核对，不能据此断言从未发出请求或补造成功。

### 作品支撑、角色与正文联动

作品支撑页修复短窗口和长文本滚动，完整开放创作契约的题材、五维画像、目标篇幅、文风与梗概锁，保存后读回，保留其他设定。结构化五维修改需重新确认；未完成审核、生成或章后分析期间的冲突写入会被拒绝，并保留编辑草稿。

角色页支持档案、关系、声线编辑、改名与确认删除。改名同步本书当前章节和当前关联资料，历史正文版本、模型输出、冻结提示词与原始审稿证据保留。保存时原子提交持久章后分析任务，章节历史可查看状态与重跑；资料保存成功和模型分析完成分别呈现。删除清理当前档案、关系、出场配置与角色记忆，保留已写正文，并阻止旧记忆重新建立已删除档案。

章节标题与正文编辑继续保留版本、冲突及迟到写入保护；本章和后章派生资料按顺序重算，成功后清理旧失败状态。关联重算不会自动改写后章正文，原写作计划也不能一概当成修改后的正文事实。

### 提示词的实际用途与删除保护

提示词广场标明已接入调用、按路径生效、生成前片段或仅关联说明。模板存在或与 DAG 关联不能单独证明它发给模型；自定义模板仍需业务功能、调用规格或工作流明确引用。

无引用自定义提示词可确认删除，内置项及仍被工作流、变量、调用规格、会话、历史调用等引用的项会说明阻止原因。编辑、回滚和删除后读取数据库当前版本，删除事务重新检查并发引用。

新书及正文共享 `semantic-style-v4` 语义审稿，读取 `anti-ai-chapter-audit` 当前激活版本，冻结版本编号和 System/User 原文作为附加文风规范。固定核心继续要求五维、完整覆盖、原文证据、JSON 及事实边界。历史 v1/v2/v3 使用当时快照，不补造新规范审核；正文 v4 提交核对真实持久请求和响应。`cliche-scan` 复用共享规范，不单独发起模型请求；生成前约束片段也不等于 Token 级中途拦截。

### 作者指定的段落句号规则

按实际换行划分自然段，每段最多出现一个中文句号“。”，需要时在段末收束，闭引号或闭括号前的段末句号仍计入本段。段内按语义使用逗号、分号或连接词，保留事实、限制条件、否定、因果和对白，不机械换标点、不删信息、不拆碎段落。标题、名称以及问号、叹号结尾无需强补句号，界面自动折行不算新段。

规则进入实际语义审稿、相关修复和正文生成模板；同段多句号按机械结构问题提供原文证据及建议，不批量修改已存稿件。当前没有独立句号计数硬拦截，也没有新增本条规则的真实模型文学效果验收。旧 `theme_integrator.py` 自动写作格式构建器仍有未统一的段落指令，不能把共享审稿 v4 接入写成所有旧生成分支均已统一。

## 升级与中断恢复

1. 退出旧版，先在原版创建并验证备份，再安装新版本；迁移及外部资源边界见[恢复说明](RECOVERY_AND_SUPPORT.md)。不要同时运行多个实例写同一书库。
2. 原有模型档案继续可读，检查自动协议、模型和思考参数；本地嵌入路径或依赖变化时按[嵌入指南](embedding_model_download_guide.md)准备。安装包不附带开发机凭据或私人书库。
3. 新书生成失败可先查看节点报告，再“继续生成”；基础设定或前置资料真实变化时重新生成受影响阶段。关闭向导只停止观察，“停止生成”才取消任务。
4. 旧宏观规划请求卡住时进入运行中心核对原请求、状态及错误。确需重新请求时先确认，返回后依次采纳、提交，再明确启动托管以写入结构树；停止状态不会自动启动执行。
