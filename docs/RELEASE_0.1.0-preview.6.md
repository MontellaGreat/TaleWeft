# 0.1.0-preview.6：新书市场画像校验修复

修改日期：2026-10-24。构建标识：`taleweft-0.1.0-preview.6-20261024`。包含 preview.5 的全部功能与修复。

## 问题与修复

新书向导按单元生成文风、五维世界观、人物、地图和剧情总纲时，内部改写了提示词，却仍使用改写前冻结的市场证据。在具有结构化市场画像的书目中，这会触发“市场画像或提示词已变化，请重新编译并审阅后生成”，阻止模型调用。审计和修复使用另一份临时提示词时也存在同样的问题。此前未配置结构化画像的测试书无法暴露这个分支。

- 分步生成现在将最终发送的提示词与其市场画像证据同时冻结。
- 偏离检测及偏离／Anti-AI 修复使用独立的调用快照和证据；临时调用不覆盖主生成会话的证据，失败和取消后也保持对应关系。
- 每次审计或修复的调用记录保存自己的市场证据，可与实际发送的提示词核对。
- 阶段恢复、下一单元准备和资料提交时，检查该阶段各会话的完整市场画像，涵盖自定义五维等基础字段之外的内容；提交前等待检查点保存后再次检查。
- 通用提示词校验继续严格执行。真实画像变化、证据缺失、来源提示词改变或未知提示词修改均不会被自动接受。

## 已卡住的任务

安装此版本后，打开原书的新书向导，在失败阶段选择“继续生成”。对于 preview.5 成功准备、因本次误报卡在生成节点的任务，系统核对原始提示词来源、市场画像哈希、当前单元、基础设定、输出绑定和已知旧提示词变换，再补齐冻结证据。已审核保存的单元不会因此重新生成。

如果确实修改了市场画像或基础设定，请对当前阶段选择“从头重新生成”；这类变更不兼容原有审核依据。修复不会为旧内容补造审核通过记录。

本轮后端相关回归 **743 项通过**，前端单测 **248 项通过**，Chromium 浏览器回归 **23 项通过**；TypeScript 与 Vite 生产构建、版本及共享配置一致性检查通过。独立审查另外复核了旧快照迁移与四类拒绝路径。

实际冻结后端连续两次通过启动、模型就绪、本地依赖、离线语义查询、数据库和地图父子关系读写、DAG 图与正常退出检查，均返回本次构建标识。包内 **167 个前端文件**与最终生产构建逐文件 SHA-256 一致；版本清单、修改声明与许可证资源也一致。

后端流程使用隔离 SQLite、真实会话／绑定／提交／扫描管线与可控模型响应；未调用付费远程模型。浏览器回归使用可控接口响应。正式书库与安装目录未被本轮测试修改，未对正式安装执行安装或卸载。

安装包为 `out/installers/TaleWeft-0.1.0-preview.6-x64-setup.exe`；旧版安装包保留。Anti-AI 规则扫描与偏离模型审核的能力边界保持原状，不保证主观文学质量。
