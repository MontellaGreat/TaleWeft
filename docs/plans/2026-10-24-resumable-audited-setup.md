# 新书向导：分步生成、可恢复审计与编辑锁定

依据用户 2026-10-24 的明确需求实施。复用本项目开源 DAGEngine、写作页 DAGCanvas、调用会话与资料提交机制，不另引入工作流框架。

## 已确认的问题

- 旧世界观一次生成五维和文风；任何错误都要重跑整次大请求。
- 工作流仅持久化状态，没有恢复生成、校验、提交所需的数据；失败后重新开始丢失中间进度。
- 结构校验不是偏离检测，也不是 Anti-AI 审计；旧向导没有真实的两项质量门禁。
- 前端编辑及 API 写入均需要审计门禁，不能只在生成时禁用按钮。
- 向导底部按钮需在有限窗口中换行，内容滚动与底栏各自约束。

## 流程与契约

世界观依次执行：文风、核心法则、地理生态、社会结构、历史文化、沉浸感细节；每个单元独立准备上下文、生成、结构校验、偏离检测及修复、Anti-AI 审计及修复、保存、回读确认。下一个单元的提示词只要求当前内容，并包含已经保存和通过审计的前置内容。

五维完成后，再对完整世界观执行结构、整体偏离与 Anti-AI 复审。需要修复时，对整体候选做有界修改，重新验证两项审计，通过后保存并回读。人物、地图及剧情总纲执行相同门禁，继续检查角色、地点层级、目标章数等原有约束。

- 工作流版本为 2；四个阶段 ID 不变。
- 节点配置包含 `action`、`unit`；普通单元的动作是 `prepare/generate/validate/deviation/anti_ai/commit/verify`。
- 候选、调用会话 ID、审计报告、提交回执及前置基准持久化；不存模型凭据。
- 默认启动从最近失败或中断运行的首个未成功节点继续；保留旧节点真实回执并注明复用来源，不伪造新执行证据。
- 恢复前比较基础设定与已确认资料；输入改变时拒绝复用过期结果，要求明确重新生成。
- 提供明确的重新生成入口，保留旧候选与运行记录。中断和取消不会释放尚未完成的数据库写入所有权。
- 审计缺失、格式错误、实际执行失败、修改后未重新审计均不得提交或解锁。
- 当前阶段未完整通过时，生成资料可只读预览，不可通过向导编辑、跳过、确认或其它写入 API 绕过门禁。
- 原有旧书和旧版本工作流不因缺少新审计而永久锁定。

## 实施分工

1. 主 agent：DAG 拓扑、节点上下文、逐节点持久化与恢复、测试整合和最终审查。
2. 生成 agent：单元提示词、候选恢复、真实偏离与 Anti-AI 审计、修复和分步提交。
3. 界面 agent：复用写作画布、进度与继续生成、只读预览、底栏布局及浏览器验证。
4. 审查 agent：服务端编辑门禁、直接提交保护与对抗测试。

所有更改保留现有功能，不覆盖正式用户书库、凭据或安装目录；验证使用项目内临时数据库和可控模型响应。

## 验收

- 五维严格顺序；后续提示词包含前置已确认维度，且只请求当前单元。
- 中间生成、偏离审计、Anti-AI、保存和回读各处故障后均可继续；已完成生成不重复调用。
- 重建 manager/重启后可恢复，过期输入不能错误复用。
- 偏离或 AI 味触发修复，修改后重新校验；审计无法完成时拒绝保存和编辑。
- 后端锁定与向导锁定一致，旧书仍可正常编辑。
- 1024×700 及常见窗口下底栏按钮不溢出，共用画布不污染写作页状态。
- 通过相关后端、前端、Chromium 回归、生产构建；更新安装包及变更说明。
