## 使用的文案

> 【段落句号约束】以实际换行划分自然段，每个自然段最多出现一个中文句号“。”，需要句号时仅在段末收束，闭引号或闭括号前的段末句号仍计入本段；段内的动作、说明与因果分句按语义用逗号、分号或必要的连接词衔接，保留原有事实、限制条件、否定、因果及对白信息；问号、叹号结尾的段落以及标题、名称无需强补句号，不得机械替换标点、删掉信息或把同一语义单元拆成碎片段落来凑数。

审稿额外要求：按文本字段分别逐段检查，同段出现多个中文句号归入 `mechanical_structure`，必须报告问题，逐字引用覆盖多个句号的原文，并给出保持语义的修订建议。这里是作者选定的写作规范，不将多个句号视为识别作者身份的依据。

用户提供的正反示例没有写入提示词。
