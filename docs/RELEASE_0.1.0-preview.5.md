# 0.1.0-preview.5：四阶段审核可见性与详情

修改日期：2026-10-24。构建标识：`taleweft-0.1.0-preview.5-20261024`。包含 preview.4 的分步生成、审计、失败恢复和编辑保护。

## 本次问题

用户反馈只有地图显示偏离检测与 Anti-AI 审计，世界观、人物和剧情总纲看不到，而且节点不能点击查看详情。

只读检查本机正式书库确认：已有世界观完成记录为旧版 6 节点，人物中断记录为旧版 5 节点，两者没有新版审核记录。后台返回当前新版定义的同时也返回历史快照，前端优先画历史图，导致新版审核节点被隐藏。另外，共用画布在接收外部只读图时直接忽略节点点击，没有发送详情事件。

## 修复行为

- 四个阶段都可以查看新版工作流定义。世界观包含文风、五维及完整复审，共 48 节点；人物、地图、剧情总纲各 7 节点。
- 当前流程定义与历史执行记录分别展示；旧记录明确提示没有这两项审核，不能被显示成已通过。
- 点击阶段卡片、画布节点或审核入口，可以查看只读详情，包括真实节点状态、报告、输出、错误、修复历史及执行证据。
- 审核报告按内容版本区分；历史通过记录不代表当前修改后的候选已通过，缺少报告也不推断成功。
- 完整世界观复审替换过的单元会明确标记为历史候选，显示复审后已确认内容与替代提交，不把原单元的通过报告称为最终版本的审核结果。
- 切换阶段时标题、进度和详情与选中的阶段一致，避免沿用最近一次地图任务的状态。
- 外部只读图发送查看详情事件，但不修改写作页的 DAG store。
- 对抗检查同时封堵旧版一键生成、后台别名和流式生成的审核锁旁路。入口及保存前均检查；即使旧任务先启动、等待模型期间才启动新版工作流，也不能把未审核内容覆盖进正式设定。没有新版未完成流程的旧书保持原有兼容行为。

## 使用方法

打开新书设置向导，点击“查看 DAG 工作流”，切换到文风 / 世界观、人物、地图或剧情总纲；点击审核节点或审核报告入口查看详情。世界观按文风、核心法则、地理生态、社会结构、历史文化、沉浸感细节及完整复审分别查看。

旧版资料不会自动被改写，也不会补造审核报告。如需要这些资料取得新版审核结果，请在相应步骤点击“重新生成”，并在确认框选择“从头重新生成”；没有生成过的步骤正常开始生成。新任务通过审核、保存和回读后才显示完成。
