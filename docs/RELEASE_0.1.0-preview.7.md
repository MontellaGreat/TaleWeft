# 0.1.0-preview.7：文风正文转换与失败恢复

修改日期：2026-10-24。构建标识：`taleweft-0.1.0-preview.7-20261024`。包含 preview.6 的全部修复。

## 问题与修复

用户遇到“文风公约为空，已阻止保存”。只读检查最新失败记录确认，模型已经返回了包含核心公约、叙事视角、语言规则等条目的多层文风对象，生成节点成功，结构校验节点因只接受字符串而失败。继续生成复用了原生成结果，所以重复出现同一错误。

- 复用项目现有开源实现 `worldbuilding_value_to_prose`，把文风对象、列表和 JSON 字符串转换为可读正文，保留嵌套标签和非空文本内容。普通文风字符串保持原有行为。
- 文风单元生成、修复、完整世界观复审采用相同规范化；提示词明确要求字符串，同时兼容已知旧版提示词变换的验证。
- 继续旧失败任务时，先核对原始调用成功、会话归属正确且调用内容与检查点候选一致，再为可读正文创建新候选并保留来源。原始输出不被覆盖，已成功的文风生成不会重复调用模型。
- 转换内容的哈希改变，旧审计被清除；新候选必须重新通过偏离检测、Anti-AI 审计、保存和回读才能确认。
- 空对象、空列表、纯数字／布尔状态、审核报告和接口错误信封继续被拒绝，避免把异常结果伪装为文风。

## 网页版

本机测试入口为 `http://127.0.0.1:8019`。先运行项目内 `out/taleweft-web-preview/打开网页版.cmd`，启动器会打开带本机会话的浏览器；单独输入地址而未建立会话时，无法读取书库数据。

测试数据位于 `out/taleweft-web-preview/data/`，来自正式桌面书库的只读快照，包含本机已保存模型配置。网页中的修改与新增任务写入隔离副本，不回写正式桌面书库。不要分享 `session-private.url` 或数据目录中的凭据文件。网页修改不会自动合并到桌面版，重要结果可使用应用导出功能保留。

本轮先部署网页测试，确认修复与回归后再构建 EXE。退出旧桌面程序后安装新版本，原失败阶段选择“继续生成”；真正修改过市场画像或基础设定时，应重新生成当前阶段。
