# 叙织 · TaleWeft v0.1.0-preview.1

这是叙织（TaleWeft）的首个公开预览版。它基于 PlotPilot v4.6.0 独立修改维护，保留上游许可、归属与修改说明。产品更名不代表与上游作者存在隶属或背书关系。

> Preview 提示：此版本适合本地试用、反馈和验证写作流程。它不代表所有模型、网站分类、DAG 托管路径或安装升级场景都已完成端到端验收。请在迁移正式作品前先备份，并先用测试书熟悉功能。

## 获取与启动

从 [v0.1.0-preview.1](https://github.com/MontellaGreat/TaleWeft/releases/tag/v0.1.0-preview.1) 的 **Assets** 下载 `TaleWeft-0.1.0-preview.1-x64-setup.exe`。按 `SHA256SUMS.txt` 校验 SHA-256 后安装，从开始菜单启动。此预览安装包尚未进行发布者代码签名。

首次启动请在设置的模型引擎中自行填写服务商、模型、服务地址和 API Key，并运行连接测试。安装包不包含服务商凭据、私人作品或开发机测试数据库。使用模型通常会通过网络发送提示词及相关创作上下文，并可能产生费用。

详细步骤见[中文使用指南](USER_GUIDE.md)。

公开自编的[六章示例稿件](../examples/fog-harbor.taleweft.json)也可从 Release 下载。桌面用户在“稿件 JSON 导入”中预览并确认即可，无需 Python 或 API Key；该文件含 2 章样稿与 4 章空稿。人物、地点等完整资料的源码导入方式与内容边界见[示例说明](../examples/README.md)。

需要完整资料的桌面用户，可同时下载 `TaleWeft-0.1.0-preview.1-full-sample-data.zip` 和 `TaleWeft-0.1.0-preview.1-sample-launcher.zip`，解压后运行启动器，选择已安装程序和测试书库。它为样书建立独立数据目录。Release 另附中文说明文档、SBOM、第三方许可与对应源码归档，以及所有附件的 SHA-256 清单。

## 本次内容

- 书库优先的作者书桌：全局创作导航、纸张式正文、章节搜索、专注阅读、九类资料面板与墨绿/浅色/深色主题；接入正式「织页书标」及桌面图标。
- 新建作品梗概最多 10,000 字。按男频、女频、双频逐级选择大类和网文主题，或自填分类，并可修改世界观基调、剧情结构、节奏把控、写作风格和特殊要求五维画像。
- 继续使用原有作品规划、设定、人物关系、地点、手稿道具、知识库、伏笔、审阅、章节生成、DAG、导入导出、提示词管理、模型控制、备份恢复等业务能力和入口。
- 章节标题和正文的版本化保存及历史查看；保存后为本章和后续章节建立派生分析任务，界面展示任务状态，失败时可以重跑。
- OpenAI Chat Completions（C）与 Responses（R）可单独选择；在“设置 → 模型引擎 → 对应角色 → 思考程度与推理参数”中展开调整，完整 AI 控制台也保留同类配置。其他模型按其适配器提供思考预算或不支持该参数。
- 章末硬状态证据不足时，增加最多一次引文专用修复。修复仅允许连续扩展原文证据，锁定已抽取的事实，并再次执行严格校验。
- 针对道具仓储迁移、人物姓名一致性、严格评分请求、浏览器禁用本地存储、保存后关联重算等问题的修复。

## 本轮验证

- 前端：24 个测试文件、206 项单元测试通过；生产构建通过。
- 后端：单元测试 2,753 项通过、7 项跳过；DAG 与集成测试 540 项通过、2 项跳过；发布收尾的样书、EPUB 和安装数据保留专项复测 20 项通过。跳过用例不计入通过数。
- Rust：2 项测试通过。冻结后端实际启动的身份验证、SQLite 建档读回、地点父子层级读回和退出清理烟测通过。
- EPUB：整书和单章导出通过 EPUBCheck 5.4.0 检查，错误、警告和致命错误均为 0。
- 浏览器：10 组真实 Chrome 操作通过，包括书库、章节切换、编辑保存、历史、九资料入口、专注、DAG 导航、思考设置、主题和窄屏。
- 编辑关联：第一章标题/正文修改后刷新读回、历史留痕，本章及第二章的顺序关联重算完成；新仓库编号进入记忆，已登记铜钥匙的持有人更新为周渡。后章正文没有被自动改写；全部历史恢复与冲突组合未人工验收。
- 测试作品《雾港来信·功能测试》的第三章实际完成 Responses 正文生成、页面保存、刷新读回，正文 1,223 字符；章后分析、摘要/记忆和演进快照后来完成，第三章级联状态为 completed。
- 实际去 AI 味执行回执显示五层提示词已应用、流式扫描和最终全文扫描均完成，保存正文哈希匹配。该次使用 warn 策略，严重命中为零。

以上是本次具体路径的证据，不等于每个模型、配置、作品或自动流程都通过。两次 C 长正文生成请求曾遭遇上游过载；R 正文生成成功，其非流式分析后来遇到超时，验证中手动切换 C 后章后分析完成。这不是全程仅用 R 的完整两章验证。对于其他供应商或网关，应先在自己的配置上做小范围试写。

## 已知范围

- 完整多章 DAG / 全托管运行未逐一真实跑完；节点和工作流界面可用不等于所有运行组合已验收。DAG 任意节点断点续跑也不应视为已支持。
- 去 AI 味的这次真实证据覆盖生成提示词、流式扫描、全文扫描和保存回执；可选自动改写路径没有包含在该次执行中。结果不保证文学质量、自然度或通过任何外部检测。
- 修改后的关联分析不会自动替作者改写后续章节正文。机器分析可能标记矛盾，仍需作者查看并决定是否修改。
- 平台题材目录是产品内置创作分类，不是所有小说网站当前目录的完整、实时镜像。
- 本轮未重新验收所有厂商协议的完整多章节流程、桌面安装升级与回滚。协议参数、推理强度和功能取决于模型、服务商及网关能力。
- Windows 安装身份与原上游应用数据目录隔离，默认不会静默导入或覆盖 PlotPilot 作品。升级前请建立并验证备份。
