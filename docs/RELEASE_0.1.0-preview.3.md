# 0.1.0-preview.3：模型就绪检查与本地嵌入下载

修改日期：2026-10-24。构建标识：`taleweft-0.1.0-preview.3-20261024`。包含 preview.2 的模型设置简化、新书 DAG 与调度修复。

## 创建书目前检查模型

- “创建第一本书”“＋ 新建书目”与侧栏创建入口统一检查已保存的语言模型和嵌入配置；新建表单最终提交前再次检查。
- 未就绪时提示 **请先配置好模型**，分组列出缺少项。点击 **打开模型控制台** 后进入需要补全的页签；两类都缺少时先进入 LLM 设置，仅缺嵌入时进入嵌入模型。
- 语言模型检查实际激活档案、模型 ID、服务地址、有效凭据、运行时状态与思考参数；独立端点模式同时检查经济和知识图谱角色。本地无鉴权网关可使用明确的免认证配置。
- 云端嵌入检查模型、地址和凭据；本地嵌入检查依赖能否导入、模型配置、tokenizer 和完整权重。托管下载文件检查长度和哈希，自备模型检查权重结构。
- 就绪接口只读，不迁移配置、不调用付费模型、不加载模型权重，也不返回密钥。它判断配置和本地资源是否完整；云端连通性由“测试连接”或实际调用确认。
- 检查失败会明确阻止进入创建流程。检查与提交期间重复点击不会重复创建书目；已有表单草稿保留。

## 模型控制台

- 原“AI 控制台”当前 UI 入口统一更名为 **模型控制台**。
- **模型名正下方**显示 OpenAI 思考程度，Anthropic / Gemini 显示思考预算；继续保留不同协议的参数约束与高级参数。
- 新默认采用 **本地嵌入模型**。已填写的云端配置不被迁移或覆盖；旧版本完全空白的云端占位配置按本地默认处理。
- 读取、保存、状态检测和下载完成的迟到响应不能覆盖新输入；未保存的新模型路径不会沿用旧路径的就绪提示。

## 下载与“连接中断”修复

旧流程仅安装依赖，没有下载权重；部分错误缺少终止事件，前端把正常错误流结束误报为“连接中断”。安装锁也可能保持占用。

新流程为 **检查依赖 → 安装并验证依赖 → 探测模型源 → 下载权重 → 校验文件 → 发布完整模型**。

| 内容 | 来源与行为 |
| --- | --- |
| Python 依赖 | 阿里云、清华、中科大、腾讯云、华为云、PyPI，失败后顺序切换；保留 HTTPS 证书校验 |
| 默认模型 | `BAAI/bge-small-zh-v1.5`，约 96 MB，512 维 |
| 模型首选来源 | ModelScope 魔搭 `AI-ModelScope/bge-small-zh-v1.5` |
| 模型备用来源 | `hf-mirror.com`，再到 Hugging Face 官方 |
| 网络检查 | 读取元数据与配置，流式探测权重端点；下载或校验失败自动换源 |
| 文件校验 | 必需文件列表、文件长度、来源 SHA-256 / Git blob 校验，再生成本地校验清单 |
| 保存策略 | 临时目录下载，完整校验后发布；取消清理临时文件，发布及恢复失败时保留旧模型备份 |

- 依赖与权重放在运行时可写数据目录；安装包不附带用户模型、凭据或作品。
- SSE 在所有终止分支返回结果；静默下载持续心跳；取消会终止本次安装进程并通知下载器，释放安装锁。
- 覆盖 ASGI 2.3 / 2.4 的真实 socket 断线，保证网络消费者退出时取消任务。依赖导入抛出 `SystemExit` 或检查超时也会返回明确失败，不会永久停在“正在验证”。
- 冻结版寻找与后端 Python 3.14 ABI 和位数相符、含 pip 的 Python；不再把后端 exe 当作 pip。若未找到，会显示对应安装说明。可以使用 `PLOTPILOT_PYTHON_EXE` 指定解释器。
- 启动外部 Python 时清理并恢复 PyInstaller DLL 搜索路径，避免冻结运行库干扰 pip；补齐可选模型依赖需要的 `filecmp`、`pickletools`、性能分析等标准库模块，修复下载后在安装包内仍无法导入的问题。
- 下载界面显示当前动作、文件进度、来源和具体错误。依赖已安装但权重缺失时仍提供下载按钮；后台依赖验证完成后自动更新状态。
- 默认模型准备成功后继续检查保存的实际模型路径。若使用自备路径，提供“填入已下载模型路径”，由作者保存后生效；不会自动切换云端配置。
- 修复依赖安装后的重启兼容：先启用验证后的本地依赖再加载向量库，避免把 FAISS 二进制当成 JSON；旧便携 JSON 可在 FAISS 可用后转换。Simple 内存对象不会误交给 FAISS writer，缺少依赖时明确报错并保留原索引。
- 启动章节恢复先查队列；没有待恢复任务时不创建本地模型服务，有任务时在线程中初始化，避免大依赖与权重加载阻塞启动和健康检查。

- 创建前检查不测试云端模型的网络连通性；本轮没有调用作者的付费模型。测试报告只覆盖上述默认 BGE 模型与本次 Windows Python 环境，不代表所有自备模型架构均已验收。

可复查记录位于 `out/model-readiness-tests/`，包括 `backend-final-all.log`、`frontend-final.log`、`browser-final.log`、`network-result.json`、`runtime-live/runtime-result.json`、`packaged-local-final.log`、`packaged-local-restart.log` 与 `runtime-live/smoke-result.json`。曾出现的依赖超时记录为 `packaged-local-first-timeout.log`。

## 使用位置

打开首页 **模型控制台 → LLM 设置**，补齐并启用模型档案；思考参数紧接模型名。再进入 **嵌入模型**，保留本地模式，点击 **下载并准备本地模型**。保存配置后重新点击“新建书目”。

更多步骤见 [嵌入模型配置](embedding_model_download_guide.md)。
