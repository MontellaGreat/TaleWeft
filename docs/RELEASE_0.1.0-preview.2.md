# 0.1.0-preview.2：模型设置简化与新书 DAG

修改日期：2026-10-24。构建标识：`taleweft-0.1.0-preview.2-20261024`。本轮直接修改源码，并进行隔离数据库回归；测试不改作者的正式书库。

## 模型设置

- 删除 LLM 控制台中的“导入厂商预设”整块界面、导入操作及配置档案的预设选择。
- OpenAI C / OpenAI R 合并为一个 **OpenAI 自动**。保存时使用 `protocol=openai`、`endpoint_kind=auto`，关闭旧版强制 Chat 标志；旧档案仍能读取，保存后归一化。
- Anthropic Messages、Gemini generateContent、API Key、Base URL、角色配置、思考程度 / 思考预算及高级参数继续保留。
- 拉取模型后自动展开完整模型列表，可直接选择或搜索；当前已选模型继续显示。拉取为空或失败时保留手填能力；切换档案、地址或凭据后，旧请求不会覆盖新档案结果。
- 自动协议优先 Responses，只在确认端点不支持、尚未输出正文时切换 Chat Completions。401/403、429、502、网络超时、连接失败、模型不存在或参数不支持不会触发误切换。取消及已输出的流不会重新发起另一份生成。
- 修复 Responses 自定义扩展参数被直接当成 SDK 关键字参数、发送前就触发 `TypeError` 的问题，改用 SDK `extra_body`。

## 409 的根因与调度修复

诊断中的 `POST /dag/{novel_id}/run` 返回 409，与执行归属冲突有关：桌面独立守护进程使用复制的旧循环，漏掉持久化控制命令消费和租约续期。启动请求可能一直 pending，小说看起来 stopped，但启动预约仍阻止 DAG。

- 桌面进程统一使用公共守护循环，先处理命令，再轮询小说；统一处理停止确认、执行标记及续租。
- 过期的 pending 启动命令明确失败，不在稍后重新抢占并意外启动。
- 状态 API 增加控制说明、命令等待时间、执行器 PID、租约所有者、任务 ID、到期时间和预约过期状态。
- DAG 的 409 区分“全托管启动等待确认”和有效执行锁。真实并发仍被阻止，不通过删除命令或绕开互斥来掩盖冲突。
- 本轮没有对用户诊断文件中的书目执行清库、删命令或直接改状态；旧安装器需要更新到本轮构建后才包含守护进程修复。

## 新书向导接入真实 DAG

四个阶段依次依赖：**文风 / 世界观 → 人物 → 地图 → 剧情总纲**。阶段之间保留编辑、保存和作者确认，不自动跳过核对。

| 阶段 | 实际节点顺序 | 校验与保存 |
| --- | --- | --- |
| 文风 / 世界观 | 准备资料 → 联合生成 → 校验文风 → 校验世界观五维 → 保存资料与关联 → 回读确认 | 非空文风、五维全部合同字段；保存到 Bible 文风、Worldbuilding V2 和变量中心 |
| 人物 | 准备资料 → 生成人物 → 校验角色结构 → 保存资料与关联 → 回读确认 | 非空名单、有效姓名、姓名唯一，回读实际人物记录 |
| 地图 | 准备资料 → 生成地图 → 校验地点关联 → 保存资料与关联 → 回读确认 | 复用地点层级规范化，保存地点及父子关联，回读核对 |
| 剧情总纲 | 准备资料 → 生成总纲 → 校验总纲结构 → 保存资料与关联 → 回读确认 | 复用总纲阶段规范化，保存并从变量中心回读 |

文风和世界观的联合生成复用一次现有 CPMS 调用；后续两个校验节点分别执行，不把界面节点伪装成多次模型调用。所有阶段沿用 AI Invocation、采纳提交及现有提示词资产。

- 向导新增进度条、当前动作、已用时间、完成节点数、错误、停止和重新连接。
- 新增 **查看 DAG 工作流** 按钮，使用只读 Vue Flow 图显示四阶段依赖和实际节点状态。
- 进度按完成节点计算。模型调用期间显示“正在生成”，不伪造 token 级百分比；保存和回读通过后才显示完成。
- 关闭向导只停止前端观察，后台继续；重新打开读取持久化任务，不重复启动。显式停止会取消并等待实际任务退出，再释放执行归属。
- 断线可重新连接；应用重启且原执行租约失效时，未完成任务显示中断，可重试当前阶段。
- 开书、章节 DAG、全托管共用按书互斥租约。长调用续租，节点执行前再次核对归属，失去租约后阻止保存。
- 开书图与章节图分开，开书内部节点不会出现在章节节点选择器里，也不能混入章节生产流程。

## 联动保存与审查中追加修复

- 修复变量绑定在排队事务提交之前读取查询结果的问题，改为在同一 SQL 中计算版本身份。绑定初始化或读取失败时明确阻断，不再把失败当成“没有绑定”而跳过，也不覆盖用户自定义绑定。
- 修复人物 / 地点回读把 dataclass 当成 Pydantic 模型调用 `model_dump()` 的问题。
- 修复角色姓名前后空白经正常保存裁剪后被误判为保存不一致的问题。
- 世界观前置检查逐维验证实际字段内容，空字典中的字段名不能冒充完整世界观。
- 模型失败、无效 JSON、校验失败、回读不一致都不会让 DAG 显示成功。模型失败对应的 Invocation 同步标为失败。
- 补齐启动即停止、取消时仍在写 SQLite、两执行器争抢、租约中途丢失、旧内存记录掩盖中断等并发边界。
- 修复前端迟到的轮询响应覆盖“已停止”状态，以及世界观读取错误被吞掉、剧情总纲显示虚构生成子阶段的问题。
